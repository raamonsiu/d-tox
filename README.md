# D-TOX

App Android de lectura para la desintoxicación digital: un lector calmado y austero, más lecturas cortas y completas de filosofía clásica y divulgación científica.

**Estado:** planificación. No hay código todavía.

**Versión:** <!-- version -->0.31.0<!-- /version -->

Toda la documentación de producto y diseño está en [`docs/`](docs/README.md).

## Privacidad

Sin cuentas, analítica ni anuncios. La única conexión a internet (permiso `INTERNET`) descarga por HTTPS el feed estático de lecturas cortas; libros, notas y ajustes no salen del dispositivo.
